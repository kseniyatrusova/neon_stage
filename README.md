# NEON STAGE

Учебный сайт для выбора концертов и бронирования мест на интерактивной схеме зала.

## Запуск

Откройте `index.html` в браузере. Сборка, сервер и установка пакетов не нужны.

## Что есть на сайте

- Афиша из шести демонстрационных концертов в Санкт-Петербурге.
- Вырезанные портреты артистов из `img/` на фоне неоновых кругов в карточках.
- Фильтры по жанру и минимальной цене билета.
- Схема зала с танцполом без нумерации и 50 VIP-местами на каждом концерте.
- Структуры залов различаются: 25 мест с каждой стороны или боковые VIP-зоны по 20 мест и 10 мест сзади.
- Схема мест и список синхронизированы; схема танцпола позволяет выбрать число входных билетов.
- Фильтры по VIP-зоне и цене, выбор нескольких мест или билетов на танцпол, расчёт суммы.
- Учебные брони, сохранение в `localStorage`, отмена и сброс демо.
- Адаптивная тёмная клубная тема с неоновыми цветами, поддержка клавиатуры.

## Демо и ограничения

Артисты заданы по выбранной теме. Даты, площадки и наличие мест вымышлены и предназначены только для демонстрации интерфейса. Это не афиша реальных мероприятий. Сайт не принимает оплату, не использует сервер и хранит учебные брони только в текущем браузере.

## Нейросеть

Для создания и доработки сайта использовался ChatGPT / Codex.

## Ключевые запросы в этой работе

1. «Сделай сайт бронирования билетов на концерты в Санкт-Петербурге для выбранных русских исполнителей. Используй HTML, CSS и ванильный JavaScript».
2. «Оформи сайт как тёмную клубную афишу с неоновыми акцентами и адаптивными карточками концертов».
3. «Построй схему с большим танцполом без нумерации, 50 VIP-местами и разной структурой зон для разных концертов».
